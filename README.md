# DexRemo project site

Source of https://dexremo.github.io — the project page for
"DexRemo: A Force-Sensing Hand Platform and Task Suite for Contact-Rich Removal Manipulation".

Plain HTML, CSS and JavaScript, with no build step. To preview locally:

    python3 -m http.server 8000

Links, release status, authors and 3D models are all set in `assets/js/config.js`.
